First, Please create a README.md for a Terraform module based on the following requirements.

## Items to Include in the README.md

1. **Title and Module Overview**

   - Name of the module
   - Concise explanation of the module's purpose and functionality
   - Supported cloud provider(s) (AWS, Azure, GCP, etc.)

2. **Usage Examples**

   - Usage example (written in code blocks)
   - Examples of how to use the outputs

3. **Requirements**

   - Required Terraform version
   - Required providers and their versions
   - Other prerequisites

4. **Providers**

   - List of providers used by this module

5. **Resources**

   - List of resources created or managed by this module

6. **Inputs**

   - Detailed table format description of each input variable
   - Variable name, description, type, default value, and whether it's required

7. **Outputs**

   - Detailed table format description of each output value
   - Output name, description, and value
