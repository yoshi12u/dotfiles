# dotfiles

Personal development environment for macOS (Apple Silicon), managed declaratively with [Nix flakes](https://nixos.wiki/wiki/Flakes) and [Home Manager](https://github.com/nix-community/home-manager).

One command installs every tool and links every config file:

```bash
home-manager switch --flake .#aarch64-darwin
```

## Highlights

- **Declarative and reproducible** — packages, dotfiles, and shell integrations are all defined in Nix; `flake.lock` pins exact versions.
- **Vim-flavored everywhere** — the same muscle memory works across Neovim, Helix, Zed, the shells, and Zellij (see [Keybinding conventions](#keybinding-conventions)).
- **Catppuccin Mocha everywhere** — WezTerm, Zellij, Neovim, Helix, and Zed share one color scheme.
- **AI-assisted commits** — a custom [blink.cmp](https://github.com/saghen/blink.cmp) source suggests Conventional Commit titles generated by the Codex CLI from the staged diff.

## Repository layout

```
.
├── flake.nix                # Flake entry point (aarch64-darwin only)
├── flake.lock               # Pinned nixpkgs / home-manager versions
└── home/
    ├── base.nix             # Platform-neutral packages, programs, and dotfile links
    ├── darwin.nix           # macOS additions (imports base.nix)
    └── config/              # Plain config files deployed by Home Manager
        ├── nvim/            # Neovim (LazyVim) — see lua/ai/ for the commit helper
        ├── helix/           # Helix editor
        ├── zed/             # Zed editor settings and keymap
        ├── wezterm/         # WezTerm terminal
        ├── zellij/          # Zellij multiplexer (locked-by-default keybindings)
        ├── nushell/         # Nushell (primary shell) + darwin overlays
        ├── zsh/             # Zsh fallback shell
        ├── git/             # Git include config, commit template, global ignore
        ├── karabiner/       # macOS keyboard remapping
        └── claude/          # Claude Code settings (deployed to ~/.claude)
```

`base.nix` holds everything that is not macOS-specific; `darwin.nix` imports it and adds macOS-only packages and files. Files under `home/config/` are linked into place (mostly under `~/.config`) by Home Manager, so edit them here and re-run the switch command rather than editing the deployed copies.

## Installation

### Prerequisites

- macOS on Apple Silicon
- [Nix](https://nixos.org/download.html) with flakes enabled (`experimental-features = nix-command flakes` in `nix.conf`; the [Determinate Systems installer](https://github.com/DeterminateSystems/nix-installer) enables this by default)

### Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/yoshi12u/dotfiles.git ~/ghq/github.com/yoshi12u/dotfiles
   cd ~/ghq/github.com/yoshi12u/dotfiles
   ```

2. Adjust `home.username` and `home.homeDirectory` in `flake.nix` if you are not the original author.

3. Build and activate (the first run bootstraps Home Manager itself):

   ```bash
   nix run home-manager/master -- switch --flake .#aarch64-darwin
   ```

   Once installed, subsequent activations are just:

   ```bash
   home-manager switch --flake .#aarch64-darwin
   ```

Neovim plugins are managed separately by lazy.nvim and install themselves on first launch.

## Updating

```bash
nix flake update                             # bump nixpkgs and home-manager
home-manager switch --flake .#aarch64-darwin # apply
```

## Keybinding conventions

The same conventions are wired into Neovim, Helix, Zed, and the shells wherever each tool allows:

| Binding | Meaning |
| --- | --- |
| `H` / `L` | Start / end of line (normal & visual mode) |
| `;` | Enter command mode (swapped with `:`) |
| `Ctrl-f` / `Ctrl-b` | Forward / back one character (insert mode and shells) |
| `Ctrl-d` / `Ctrl-h` | Delete / backspace (insert mode) |
| `Ctrl-h/j/k/l` | Move between panes (Zed, Helix, Neovim windows) |
| `Ctrl-g` | Fuzzy-jump to a ghq-managed repository (zsh & nushell) |
| `R` | Replace with register (substitute.nvim / Zed equivalent) |

Zellij starts **locked** so its keys never collide with editor bindings: `Ctrl-s` toggles the normal mode, where single keys manage panes and tabs vim-style (`v`/`s` split, `h/j/k/l` focus, `c` new tab, `[`/`]` switch tabs, `e` scrollback, `d` detach), and every action drops straight back to locked mode.

## AI commit assistance

`home/config/nvim/lua/ai/git_codex.lua` implements a blink.cmp completion source that is active only in `gitcommit` buffers. When the cursor sits on the empty first line, it pipes `git status` and the staged diff (capped at 6,000 characters) to `codex exec` and offers up to three Conventional Commit titles as completions. It activates only when the `codex` CLI is on `$PATH`; GitHub Copilot completions are also enabled in commit buffers.

Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/), scaffolded by `home/config/git/commit-template.txt`.
